# Design records

Significant, durable decisions about ci-deploy and their rationale. One file per decision,
numbered in order. A record is amended (dated, linked) when the decision changes, or superseded
by a new record that links back; it is never rewritten to hide what was decided before.

Each record states the context, the decision, the alternatives considered, the consequences and
the limits of the evidence behind it. Current behaviour and procedures live in the other
documents under `docs/`, not here.
